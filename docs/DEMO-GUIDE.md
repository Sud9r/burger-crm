# Сценарий демонстрации проекта

Этот сценарий поможет быстро показать CRM на собеседовании, в портфолио или во время ревью.

## Подготовка

1. Запустите проект командой `npm install` и `npm run dev`.
2. Откройте приложение в браузере.
3. При необходимости сбросьте демонстрационные данные в разделе **Настройки**.

Все записи вымышлены. Для демонстрации не используйте реальные контакты гостей.

## Сценарий на 3–5 минут

### 1. Главная панель

Покажите сводку дня, активные заказы, последние события и чек-лист задач. Отметьте задачу выполненной и добавьте новую — состояние сохранится после обновления страницы.

### 2. Новый заказ

1. Нажмите **Новый заказ**.
2. Укажите вымышленное имя гостя, выберите блюдо и способ получения.
3. Создайте заказ.
4. Перейдите в раздел **Заказы** и покажите новую запись.
5. Измените статус заказа.

### 3. Клиенты

Добавьте гостя или откройте существующую карточку. Покажите контактные данные и заметку. При создании заказа с новым именем приложение добавит гостя в локальный список.

### 4. Меню

Переключите категорию, измените цену блюда или временно уберите позицию из продажи. Попробуйте поиск по названию.

### 5. Аналитика и акции

Поменяйте период графика, откройте список акций, создайте предложение и приостановите его переключателем.

### 6. Экспорт и оформление

Выгрузите заказы в CSV, скачайте JSON-резервную копию и переключите тёмную/светлую тему в настройках.

## Что рассказать о техническом решении

- React-компоненты разделены по экранам и повторно используемым элементам.
- TypeScript описывает доменные сущности заказа, гостя, блюда, задачи и акции.
- Данные прототипа хранятся в `localStorage`, поэтому приложение работает без сервера.
- Выгрузки CSV и JSON формируются на стороне браузера.
- Vite собирает статическую версию, которую можно разместить на GitHub Pages.
- Все контакты и бизнес-показатели в репозитории — вымышленные.

## Честные ограничения

Это однопользовательский frontend-прототип. В нём нет настоящей авторизации, базы данных, серверной проверки, синхронизации между устройствами, кассы, эквайринга или службы доставки. `localStorage` не подходит для хранения персональных данных в рабочей системе.
