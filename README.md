# 🍔 Бургерная — CRM

**Уютная CRM для небольшой бургерной.** Заказы, гости, меню, акции и аналитика — в одном интерфейсе без перегруженных таблиц.

![Обложка проекта](./docs/cover.svg)

> Портфельный frontend-прототип с вымышленными данными. Не подключён к кассе, доставке, платёжным системам или серверной базе данных.

Архитектура и ограничения описаны в [docs/ARCHITECTURE.md](./docs/ARCHITECTURE.md). Сценарий демонстрации для собеседования — в [docs/DEMO-GUIDE.md](./docs/DEMO-GUIDE.md).

## Возможности

- **Главная:** выручка и заказы за день, средний чек, статусы заказов, последние заказы и задачи.
- **Заказы:** создание, поиск, фильтры, изменение статуса и выгрузка CSV.
- **Клиенты:** карточки гостей, контакты, заметки, история заказов и экспорт CSV.
- **Меню:** категории, цены, описания, добавление, редактирование, удаление и доступность блюд.
- **Аналитика:** показатели по истории заказов, график выручки за выбранный период и распределение позиций по категориям.
- **Акции:** создание предложений, включение и приостановка.
- **Настройки:** светлая и тёмная темы, резервная копия JSON и восстановление демо-данных.
- **Удобство:** адаптивная вёрстка, поиск по разделу, `Ctrl/⌘ + K`, уведомления и всплывающие сообщения.

## Технологии

- React 19 и TypeScript 5
- Vite 6
- Tailwind CSS 4 и собственные CSS-переменные
- Lucide React
- `localStorage` для локального хранения демонстрационных данных

## Запуск локально

### Требования

- Node.js 20 или новее
- npm (входит в установку Node.js)

### Windows

1. Скачайте архив или клонируйте репозиторий.
2. Откройте папку проекта.
3. Дважды нажмите `run.bat` либо выполните в терминале:

```bash
npm install
npm run dev
```

4. Откройте `http://localhost:5173`.

### macOS / Linux

```bash
chmod +x run.sh
./run.sh
```

Или выполните вручную `npm install`, затем `npm run dev`.

## Публикация на GitHub Pages

В `.github/workflows/deploy.yml` настроена автоматическая публикация.

1. Создайте публичный репозиторий, например `burger-crm`.
2. Отправьте содержимое проекта в ветку `main`.
3. Откройте **Settings → Pages → Build and deployment**.
4. Выберите **GitHub Actions** в качестве источника.
5. После отправки изменений workflow проверит типы, соберёт приложение и опубликует `dist/`.

Пример команд для первой публикации:

```bash
git init
git add .
git commit -m "Initial Burger CRM prototype"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/burger-crm.git
git push -u origin main
```

## Данные и безопасность

- Все имена, телефоны, email и показатели вымышлены. Не добавляйте в демонстрационный проект настоящие данные гостей.
- Данные сохраняются в `localStorage` текущего браузера и не синхронизируются между устройствами.
- Некорректные или устаревшие данные хранилища проверяются при загрузке; при ошибке приложение возвращается к безопасному набору демо-данных.
- Если браузер запрещает локальное хранилище, приложение продолжает работать в текущей вкладке и предупреждает, что изменения не сохранятся после её закрытия.
- CSV-экспорт защищён от запуска формул из пользовательских значений.
- В репозитории нет API-ключей, паролей и ссылок на рабочие базы данных. `.env.example` содержит только публичные настройки интерфейса.

## Ограничения прототипа

Это однопользовательский frontend-прототип, а не готовая к эксплуатации CRM. Пока нет сервера и базы данных, авторизации и ролей сотрудников, синхронизации, интеграций с кассой или доставкой и отчётов на основе реальных платежей. Некоторые декоративные элементы графиков остаются демонстрационными.

## Возможное развитие

- Серверный API и база данных с миграциями.
- Авторизация, роли сотрудников и журнал действий.
- Полноценная корзина заказа с несколькими позициями и историей статусов.
- Управление складскими остатками и себестоимостью.
- Аналитика по каналам продаж и повторным покупкам.
- Интеграции с кассой и службами доставки.
