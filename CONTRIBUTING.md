# Contributing

Thanks for considering a contribution!

## Before opening a pull request

1. Open an issue for a substantial change so the direction can be discussed.
2. Keep interface copy in natural Russian. English technical documentation is welcome in `README.en.md`.
3. Never add real personal data, credentials, API keys, or private service URLs.
4. Keep the demo usable without a backend and make the prototype's limitations explicit.
5. Run `npm run typecheck` and `npm run build` before submitting.

## Pull request checklist

- [ ] The change works on desktop and mobile widths.
- [ ] Keyboard focus remains visible and controls have accessible labels.
- [ ] Demo data is fictional.
- [ ] No secrets or real customer data are included.
- [ ] Documentation is updated when behaviour or setup changes.
